# 沉星之序地图 0.1.6

原生 Win32/GDI/GDI+ 与 C# WinForms，无网页框架或新组件依赖。
地图沿用语义状态色；界面为深墨绿、暖金细线、游戏自带思源宋体 CN SemiBold。
地图为主内容，进度与既有区域名次之。8/16/24 间距和 12/14/16/18/24/28 字号分级。
